# fault-catalog

## Overview

Maintains the experiment fault catalog and linked Fault Category Records. It extracts evidence-backed fault types, reconciles occurrences and statuses, and selects controlled targets for future experiments.

## When to use it

- Analyze experiment evidence for candidate fault categories.
- Reconcile an occurrence or status with existing records.
- Select the next unresolved fault for a controlled experiment.

## Example prompts

- "Extract and reconcile faults from this experiment."
- "Update the catalog status using this evidence."
- "Select the next measurable fault target."
