# experiment-observations

## Overview

Analyzes terminal artifacts from completed experiments and publishes a traceable, evidence-backed observations report. It validates scoring provenance, compares only equivalent runs, and reconciles supported fault evidence without giving model-selection advice.

## When to use it

- Analyze one completed benchmark experiment.
- Compare terminal runs whose fixed controls are equivalent.
- Publish observed fault evidence after lifecycle handoff.

## Example prompts

- "Analyze this completed experiment and publish observations."
- "Compare these equivalent terminal runs."
- "Reconcile the observed faults and return the concise results view."
