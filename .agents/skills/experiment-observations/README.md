# Experiment observations

## Overview

This skill turns terminal artifacts from equivalent completed experiment runs into a traceable observations report. It validates the evidence, computes comparable completed-run metrics, reconciles observed faults through `fault-catalog`, and returns a concise result linked to the full report.

## When to use it

- Compare the outcomes of completed runs that share an equivalent configuration.
- Produce an evidence-backed observations artifact after a benchmark matrix has finished.
- Summarize catalog-reconciled fault evidence without giving improvement recommendations or model-selection advice.

## Example prompts

- "Analyze the completed equivalent experiment runs and create an observations report."
- "Compare these terminal run artifacts, reconcile the observed faults, and return the concise observations view."
- "Publish an evidence-backed observations report for the completed benchmark matrix."
